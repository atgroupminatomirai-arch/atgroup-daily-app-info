プライバシーとデータの取り扱い

対象アプリ：ATGROUP Recruitment Daily。更新日：2026年11月22日。

利用目的と取得範囲

担当者が許可したGoogle広告の費用、対象スプレッドシートの集計値、求人応募通知の集計、LINE連携サービスの最終やり取り日別人数を、社内の求人実績管理に用います。Googleアカウントのメールアドレスは接続先の本人確認に用います。応募通知のメールアドレス・電話番号は同日内の重複判定に用います。

保存先と公開範囲

日別の費用・人数は指定のGoogleスプレッドシートへ反映します。認証キーは非公開GitHubリポジトリの暗号化Secretsで管理します。クラウドで新規に作成するLINE専用ブラウザーのログイン状態は、暗号化して同リポジトリのActionsキャッシュへ保存します。このサイトへ業務データや認証情報を公開しません。

処理ログには日付・費用・人数・処理結果などを記録します。認証キー、認証コード、応募通知の本文をログへ出力しない設計とし、ログの保存期間は利用する非公開リポジトリの設定に従います。初回のLINE本人ログインに限り、担当者のメール認証で保護したCloudflare経由の一時画面を使用します。

データの利用制限

取得データを販売せず、広告配信のための第三者提供や汎用AIモデルの学習に利用しません。Google APIから受け取った情報の利用と他アプリへの転送は、Google API Services User Data Policy（Limited Useの要件を含む）に従います。

接続の解除とお問い合わせ

Googleアカウントの接続済みアプリ管理から許可を取り消せます。専用アカウントの共有権限、GitHubの認証キー、暗号化したLINEログイン状態の削除は管理担当者が行います。集計済みのシートやログの削除については管理担当者へご連絡ください。
